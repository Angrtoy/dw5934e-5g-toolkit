# Hardware Mechanical Data and 3D Printable Enclosure Designs

This directory contains mechanical specifications, STEP 3D CAD models, and 3D printable STL files for integrating the DW5934e 5G M.2 module into desktop and portable setups.

---

## Directory Contents

| Component | Description |
| :--- | :--- |
| `5g-adapter-board/` | Mechanical documentation and full STEP AP214 3D PCBA assembly model (`71.00 × 62.35 mm`, 1.6mm thickness) for 5G M.2-to-USB/Ethernet adapter boards. Features clearance models for the Raspberry Pi 5 Active Cooler (13.70mm total height). |
| `mf650-cpe-case/` | Engineering design for a portable 5G CPE enclosure based on the Aleca MF650 10,000mAh battery case. Thickened to `160 × 90 × 37.9 mm` with an array of 8 SMA antenna ports (Ø6.6mm, 2×4 layout, 22mm pitch), ventilation ducting, and front display aperture. |
