# SMA 类穿板孔径试片

`build_fit_coupon.py` 生成一个 142 × 32 × 2.4 mm 的打印试片，包含标注为
**6.4、6.5、6.6、6.7、6.8 mm** 的五个圆孔。文字为顶面 0.4 mm 凹刻，孔距为
25 mm。

这是在完整 MF650 壳体打印前，给实际购得的 SMA 类穿板接头、螺母和垫片做
**机械孔径与夹持厚度**试验的独立小样。6.6 mm 只是当前 CAD 默认值，不能视为
用户接头的实测孔径；用户商家资料未给出精确穿板长度，2.4 mm 也只是可改的
试样参数。它不证明设备具有八路 RF，也不验证射频性能。

推荐将带文字的一面朝上、平放打印；先以实际接头、螺母和垫片试装，记录最合适
孔位与可接受间隙，再把结果写入主壳的可更换后部孔板参数。

输出：

- `sma_hole_fit_coupon.step`：可重新打开的 CAD 交换文件；
- `sma_hole_fit_coupon.stl`：打印网格；
- `preview.png`：由实际 STL 网格绘制的预览；
- `validation.json`：CAD/STEP/STL 几何检查结果。
