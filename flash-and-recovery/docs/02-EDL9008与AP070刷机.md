# 02 EDL 9008 与 AP070 刷机
停止条件：0489:E131、105B:E11D/E118 PCI/MHI、签名/NAK、异常存储几何或断电风险。05c6:9008 才是 qdl USB；其余不等价。
原 XML 为 39 program/31 erase，4096 sector/page、262144 block、512 MiB NAND，没有 patch XML。它 erase efs2 start_sector=1664,num=2816，覆盖 foxusr。空 filename（包括 foxnv）只是占位符。
仅历史 Windows E118 样卡完成刷写/联网；未在 Ubuntu USB9008 实机验证，不可称 E11D 通用。
先运行 sudo /bin/bash -p tools/flash-ap070-usb9008.sh --dry-run。qdl 语法：qdl --dry-run xbl_s_devprg_ns.melf rawprogram_nand_p4K_b256K.xml。若原 XML 被 qdl 拒绝，脚本只用 PACKAGE-DERIVED-NOT-OFFICIAL XML；它仅删除空 filename program，保留 erase/非空属性。
真实写入示例：sudo /bin/bash -p tools/flash-ap070-usb9008.sh --execute --variant E118 --ack-efs2-erase --ack-same-card-backup。真实写入仅接受 root、一个 05c6:9008、无 0489:E131、完整哈希，及 --execute --variant E118 --ack-efs2-erase --ack-same-card-backup。日志保存 logs。失败立即停止。
