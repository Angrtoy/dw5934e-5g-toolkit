# 04 解锁后联网
## 只读发现与验证（不改变模块状态）
mmcli --list-modems；mmcli -m N --output-keyvalue。先从该输出取得实际 SIM 对象，例如 SIM 路径含 SIM/S；令 S 为该独立 SIM 对象编号，再执行 mmcli -i S。不得把 modem N 当成 SIM N。
只读验证：mmcli -b B、ip -br addr、ip route get 1.1.1.1、resolvectl、curl --interface WWAN_IF URL。registered 或 bearer connected 不等于互联网成功。QMI只读备用仅限 dms model/ids/capabilities、uim card status、nas signal/serving/system-info、wds packet status。
## 状态改变操作（需客户授权）
mmcli -i S --pin PIN 是 PIN 验证写操作，可能消耗 PIN 尝试次数。mmcli -m N --enable 改变 modem 启用状态。mmcli -m N --simple-connect=apn=APN,ip-type=ipv4v6 建立数据会话并可能产生流量/计费。
nmcli con add type gsm ifname '*' con-name 'DW5934e WWAN' apn APN 创建连接配置；nmcli con mod 修改配置；nmcli con up 激活连接；nmcli con down 或 nmcli device disconnect WWAN_IF 断开连接。这些都是写操作，均需授权。示例：nmcli con mod 'DW5934e WWAN' ipv4.method auto ipv6.method auto；nmcli con up 'DW5934e WWAN'。
禁止将 wds start-network、dms set/reset 或 uim verify-pin 放进只读脚本。
